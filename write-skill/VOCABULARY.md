# Vocabulary

Deep-rooted terms. Reach for one of these before coining a new word.

| Term | Meaning | Use when |
|---|---|---|
| red-green-refactor | TDD loop: failing test, minimal code, refactor | building features, bugfixes |
| grill-me | one question at a time, challenge each answer | planning, requirements |
| handoff | structured state transfer between sessions | context over 65%, task switch |
| tracer bullets | minimal vertical slices for fast feedback | prototyping, exploration |
| caveman | ultra-terse style, cut tokens | internal reasoning, logs |
| fog of war | incomplete information, explore before acting | new codebase, hard tasks |
| scope lock | fix the task boundary, block scope creep | planning, implementation |
| tight loop | fast iteration with immediate feedback | tdd, debugging |
| one-question drill | one question, full answer, then the next | interviews, requirements |
| wayfinding | read-only audit of an unknown codebase | onboarding, legacy code |
| decision gate | human approval before the next phase | phased workflow, review |
| no production code | code only after a failing test | tdd, review |
| evidence-based | finish only with proof, like tests or build | verification, review |
| surgical changes | change only what was asked | review, refactoring |
| compress before continue | compact or hand off at high context | session management |
| fresh context | each subagent gets clean context | multi-agent |
| pointer not copy | reference artifacts, do not duplicate | handoff, docs |
| landmines only | only critical rules in memory files | project memory |
| create at third repeat | make a skill on the third repeat | skill management |
| temperature 0 for process | deterministic generation for tool calls | consistency |
