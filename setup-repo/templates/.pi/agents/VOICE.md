# Shared voice rules

Apply these rules to all prose outputs. Summaries, comments, and markdown artifacts must follow them. Code, identifiers, JSON, and command syntax are exempt.

## Vocabulary

Use one name for one thing.

### Banned synonyms

Do not use:

- helper, manager, utility, handler
- seamlessly, robustly, powerfully
- robust, powerful, cutting-edge, effortless, world-class, next-generation, revolutionary, state-of-the-art
- leverage, utilize, commence, initiate, obtain, acquire
- ensure, prior to, subsequent to, regarding, concerning
- additionally, furthermore, moreover
- demonstrate, perform an analysis of, carry out, make use of

Use instead: use, start, get, make sure, before, after, about, also, show, analyze, use.

## Mechanical rules

1. Use active voice.
2. Use one name for one thing.
3. Do not use marketing adjectives or banned synonyms.
4. Keep instructions under 20 words. Do not use contractions or semicolons.
5. Use numbered lists for steps. Put the condition before the command.

## Self-lint

Before finishing a prose artifact, check:

- Any sentence over 20 words? Split it.
- Any marketing adjective or banned synonym? Replace or delete it.
- Same thing named two ways? Pick one approved term.
- Any semicolon or contraction? Remove it.
